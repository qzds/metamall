## 美术方向

空间组织继续参考 [BOSS 虚拟展厅](https://group.hugoboss.com/en/newsroom/news/news-detail/boss-enters-metaverse-fashion-week-with-an-immersive-ai-inspired-showroom-experience) 的建筑/光/材质叙事，以及 [Decentraland MVFW 2025](https://decentraland.org/blog/announcements/the-ultimate-guide-to-metaverse-fashion-week-2025) 的共同活动空间与品牌展馆。采用未来时装发布会气质，场景内不嵌入参考项目截图。

| 项目 | v3 的主要问题 | v4 的落地变化 |
|---|---|---|
| 场景构图 | 单独浮岛像桌面模型 | 连续地坪、轨道顶棚、后部光墙、城市远景、上层新展馆；三品牌形成同一商业空间 |
| 镜头 | 主要是高处看模型 | 较低的默认镜头、连续影院导览、走近门面后进店、店内入口/陈列/建筑三个镜头 |
| 品牌建筑 | 小型门面和道具感重 | 云裳宽拱入口与庭院；极简悬挑框架/金属/玻璃；青禾完整肋架/玻璃温室/绿植 |
| 服装 | 平面挤出轮廓 | 连续曲面、肩颈袖口、领片/衣襟/扣子、裙褶和裤装分件；仍明确是款式示意 |
| 材质与灯光 | 偏灰、整体缺少重点 | 深底、品牌冷暖重点光、木/石/织物程序纹理、金属环境反射；反射覆盖层控制权重 |
| UI | 大标题、卡片与画面争空间 | 缩小标题、薄边框与目的地导视；漫游/影院导览时收起主文案 |

## 模块边界

| 文件 | 职责 |
|---|---|
| `static/js/world/runtime.js` | 渲染器、相机、环境、阴影、反射、画质、动画循环、ResizeObserver、页面生命周期 |
| `world/architecture.js` | `buildPavilion` 共同生成门面/建店预览/正式展厅；`buildAtrium` 生成公共建筑 |
| `world/garments.js` | 类别服装、人体陈列、曲面衣片与细节 |
| `world/art.js` | 材质/纹理、建筑几何、文字面板、植物、静态合批 |
| `world/resources.js` | 几何/材质/纹理/反射目标的统一释放 |
| `world/visitor.js` | 主角色载入与动画、键盘/触摸移动、边界、附近入口 |
| `world/district.js` | 商圈组织、入口拾取、传送过渡、导览和场景 UI 协调 |
| `world/showroom.js` | 商品拾取与聚焦、镜头、预览刷新、模型旋转 |
| `mall/scene.py` | 后端统一场景规范；商圈现在直接携带正式店铺的同一份规范 |

根目录 `district.js`、`store-core.js`、`store-world.js` 保持轻量入口/兼容导出；不再并行维护旧的巨大场景实现。业务交易模块保留已验证的事务与权限边界。没有引入 Vue/React 或前端构建系统。

## 性能取舍与回归

- 静态建筑按材质合并；商品保持独立以支持拾取和旋转。
- 商圈反射 1024，静止相机缓存 100ms，移动立即更新；店内反射 768。阴影 1024，静态缓存，主角色行走每 4 帧刷新。流畅模式关闭反射/阴影/辉光，像素比 .85。
- 发现招牌参与阴影时，反复建店会产生持续纹理增长；将文字和发光面板排除出阴影投射后，线上 12 次结构切换纹理稳定 28、反射目标稳定 1。没有关闭着色器错误检查。
- 23 项 Django 测试通过，新增“商圈与正式店铺共用场景规范”回归。并发业务验证仍通过。
- 三家实际 3D 门面点击进入、hover 指针、浏览器后退、店内镜头、10 次完整切店、导览复位与拖动防误入均实际验证。
- 新版真实发布“织界未来店”（`yunchang-store-70b1f4`，艺廊/岛式/14×11/冷光/861）。新库中原 v3 自动生成样例保留为草稿，无订单引用；旧 3001 数据不受影响。
- 线上订单 `D6A336C0B6DC`：角色行走并按 E 进入云裳、点击立体衬衫、领券、数量 2→1、299−30=269、模拟支付、后台查看均通过。

实测环境：Chrome 155 / Intel Iris Xe / DPR 1。两种窗口 1440×1000、1920×1080，每次预热 1.2 秒后 rAF 采样 3 秒：商圈高清静止约 54.3 FPS、影院移动导览约 45.7 FPS、流畅约 59 FPS，三个店与建店器约 60 FPS。商圈调用中位数 194，范围 194–373，统计覆盖反射与后处理。具体条件、完整数据和原始错误收集见 `验证数据/v4-*.json`。

启动时曾观察到 Intel 着色器编译 X4122 极小浮点精度 warning；最终性能采样的 `warnings` 为空。当前验证路径无 pageerror、HTTP 4xx/5xx 资源失败。未测跨设备、多人联网或商业压力负载；不把静止 FPS 当作移动 FPS。
